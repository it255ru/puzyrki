# Пузырьки

Аркада для 1–2 игроков на одном устройстве. Вся игра — один файл `index.html` (HTML + Canvas + JS, без сборки). Дополнительные ресурсы (картинки, звуки) лежат в `assets/` и подключаются относительными путями. Хостинг — GitHub Pages (https://it255ru.github.io/puzyrki/), репозиторий публичный: не коммитить секреты и личные данные. Документация и бэклог — в `docs/`.

## Правила работы

1. **Trunk-based development.** Единственная долгоживущая ветка — `main`, она всегда рабочая. Любая правка — короткая ветка от `main` (`fix/…`, `feat/…`, `docs/…`, `chore/…`), живёт не дольше дня-двух, сливается в `main` через PR (squash) после зелёного CI. Крупные фичи вводить небольшими шагами, незавершённое прятать за флагом/константой.
2. **После каждой правки** запускать `npm test` и проверять работу всех функций игры; если правка затрагивает ввод, меню, отрисовку, игровой цикл, мышь или масштабирование — ещё и `npm run test:e2e` (реальный Chromium; локально без загрузки браузера: `PW_CHANNEL=chrome`). Подробности — `docs/testing.md`. Если баг исправлен — снять `todo` с соответствующего теста. Новую функцию — покрыть тестом. Красные тесты не коммитить.
3. Игра — один файл: не выносить код в отдельные .js; ресурсы — только в `assets/`.
4. Максимум 2 игрока.
5. Любой найденный дефект — в `docs/issues/issue-<важность>-<название>.md`, статус отражать в `docs/backlog.md`; изменения — в `docs/changelog.md`.
6. Коммиты: короткий заголовок в повелительном наклонении, ссылка на issue в теле. Автор коммитов — noreply-адрес GitHub (настроено локально).

## Версия сборки

В `index.html` строка `const BUILD = "__BUILD__"` — заглушку не менять: при публикации её заменяет workflow Pages (хеш коммита и время), игра показывает «версия: …» на титульном экране и на паузе. Если пользователь сообщает о «старом» поведении, сначала сверить метку версии.

## Команды

- `npm test` — модульные тесты (`node --test tests/`).
- `npm run test:e2e` — браузерные тесты Playwright (`e2e/`); `npm run test:all` — оба набора.
- Запуск вручную: открыть `index.html` в браузере.
