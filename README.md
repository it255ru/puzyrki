# Пузырьки

Аркада для 1–2 игроков на одном устройстве: стреляйте гарпуном вверх, шары лопаются и дробятся, пока не исчезнут. Игра — один файл [index.html](index.html), без сборки; ресурсы — в [assets/](assets/).

## Запуск
Играть онлайн: https://it255ru.github.io/puzyrki/ — или откройте `index.html` в браузере.

## Разработка
```
npm test
```
Правила ветвления (trunk-based) и проверки — в [CLAUDE.md](CLAUDE.md). Документация — [docs/](docs/README.md), бэклог — [docs/backlog.md](docs/backlog.md).
