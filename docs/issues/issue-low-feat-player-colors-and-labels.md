# Цвета и метки игроков

- **Важность:** low
- **Тип:** feature / a11y
- **Статус:** open
- **Решение:** [decisions.md п. 11](../decisions.md)

## Требование
- Игрок 1 — синий, игрок 2 — оранжевый (различимы при дальтонизме); убрать красный/зелёный.
- Над игроком показывается метка «1» / «2», цвет метки контрастен фону.
- Убрать из `playerColors` лишние цвета (см. [два игрока](issue-medium-limit-to-two-players.md)).

## Тесты
`playerColors` содержит два цвета; метка рисуется для каждого игрока.
