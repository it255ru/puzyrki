# Скорость игры зависит от частоты монитора

- **Важность:** medium
- **Тип:** bug (архитектура игрового цикла)
- **Статус:** done (PR feat/fixed-timestep)
- **Где:** [index.html](../../index.html) — `step()`, `Circle.update`, `Player.update`, таймеры в кадрах

## Описание
Логика выполняется один раз на каждый вызов `requestAnimationFrame`, а все скорости/таймеры заданы в «на кадр» (`5 * speed`, `levelCountdown = 90`, `invulnerableTimer = 120`, `cooldown = 15`). На 144 Гц игра идёт в 2,4 раза быстрее, чем на 60 Гц; при просадках FPS — медленнее.

## Решение
Фиксированный шаг логики (accumulator, 60 Гц) с независимой отрисовкой, либо перевод на `deltaTime`. Предпочтителен фиксированный шаг — сохраняет текущую настройку баланса.
