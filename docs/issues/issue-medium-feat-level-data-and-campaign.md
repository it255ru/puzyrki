# Уровни как данные и кампания из 10–15 уровней

- **Важность:** medium
- **Тип:** feature
- **Статус:** in progress — часть 1 (данные уровней, валидация, пересоздание шаров) сделана; осталась кампания 10–15 уровней, обучающие уровни и баланс
- **Решение:** [decisions.md п. 6](../decisions.md) — вариант A

## Требование
- Уровни описываются данными: `{ balls: [{size, x, y, dx, color}], spikes: {...} }`; `loadLevel()` создаёт объекты заново (закрывает [issue](issue-high-level-state-not-reset.md)).
- 10–15 уровней с нарастанием сложности. Первые три — обучающие: стрельба, подбрасывание, шипы. Подсказки на экране уровня.
- Проверка данных при загрузке: размер в допустимом диапазоне, координаты в границах, иначе понятная ошибка ([issue](issue-medium-game-loop-crash-halts-game.md)).
- Исправить цвета ([issue](issue-low-level5-color-low-contrast.md)).

## Тесты
Каждый уровень проходит валидацию; ни один шар не стартует на игроке; уровень проходим (симуляция: гарпун способен достичь каждого шара); повторная загрузка даёт исходное состояние.

## Зависимости
Баланс после физики и фиксированного шага.
