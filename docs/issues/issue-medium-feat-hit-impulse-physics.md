# Физика шара: сохранение энергии и подбрасывание при попадании

- **Важность:** medium
- **Тип:** feature
- **Статус:** open
- **Решение:** [decisions.md п. 1](../decisions.md) — вариант A

## Требование
- Нормальная физика: гравитация + упругий отскок от пола с коэффициентом 1.0 (вместо фиксированного `bs`). Высота прыжка определяется высотой падения.
- Попадание гарпуном добавляет шару вертикальную скорость вверх (импульс). Серия точных попаданий поднимает шар до потолка.
- Высота подбора предсказуема: для каждого размера задан импульс, подобранный так, чтобы серия попаданий достигала потолка.

## Зависимости
Фиксированный шаг и интерполяция (готово: [#6](issue-medium-frame-rate-dependent.md)), плавность ([#6a](issue-medium-animation-jitter.md), пункты 2–5), исправление пола/стен, окружности ([#5](issue-medium-aabb-circle-collision.md)), шар размера 6 ([issue](issue-low-biggest-ball-exits-top.md)).

## Тесты (новые)
- Шар после отскока возвращается на высоту падения (± погрешность).
- Попадание увеличивает скорость вверх; траектория детерминирована.
- Для каждого размера: N попаданий достаточно, чтобы достичь потолка.
- Результат не зависит от частоты кадров.
