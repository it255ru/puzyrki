# Столкновения шаров считаются по квадрату, а не по окружности

- **Важность:** medium
- **Тип:** bug (геймплей)
- **Статус:** done (PR feat/physics-elastic-circles)
- **Где:** [index.html](../../index.html) — `Circle.intersects()`, `checkHit()`

## Описание
`Circle.intersects` сравнивает прямоугольники (bounding box). У углов квадрата шар «есть», а окружности там нет (до ≈29 % радиуса). Игрок и гарпун получают попадания по пустому месту: тонкий гарпун цепляет «воздух» рядом с шаром, а игрок гибнет от шара, к которому формально не прикоснулся.

## Решение
Заменить на проверку «прямоугольник – окружность»: ближайшая к центру точка прямоугольника, расстояние ≤ r. Оставить `bounds()` для грубой проверки.
