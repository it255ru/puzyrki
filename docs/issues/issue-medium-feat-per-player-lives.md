# Раздельные жизни и неуязвимость у каждого игрока

- **Важность:** medium
- **Тип:** feature
- **Статус:** open
- **Решение:** [decisions.md п. 5](../decisions.md) — вариант A

## Требование
- У каждого игрока свои жизни (`MAX_LIVES = 3`) и своя неуязвимость (мигает только он).
- Потерявший жизнь возвращается на старт; уровень не перезапускается, пока остался живой игрок. Шары не сбрасываются.
- Потерявший все жизни выбывает, второй продолжает.
- Уровень перезапускается (с исходными позициями шаров, [issue](issue-high-level-state-not-reset.md)) и жизни сбрасываются только при выбывании обоих → GAME OVER.
- HUD показывает жизни каждого игрока.

## Тесты
Касание шара отнимает жизнь только у задетого; неуязвимость персональная; выбывание одного не заканчивает игру; GAME OVER при выбывании обоих; победа учитывает только живых; один игрок (режим 1P) работает как раньше.
