# Автотесты, проверка на каждую правку и CI

- **Важность:** medium
- **Тип:** infrastructure
- **Статус:** in progress
- **Где:** `tests/`, `package.json`, `.github/workflows/`, `CLAUDE.md`

## Требование
После каждой правки запускаются тесты и проверяются все функции игры.

## Сделано
- `npm test` (встроенный `node:test`, без зависимостей). Харнесс `tests/harness.js` запускает скрипт из `index.html` в Node с заглушками DOM/Canvas; игра остаётся одним файлом.
- 60 тестов: загрузка, физика, деление и попадания, ввод и игроки, жизни/уровни/победа/пауза/отладка, отрисовка HUD и оверлеев.
- Известные дефекты закреплены тестами `todo` со ссылкой на issue: когда баг исправлен, тест начнёт проходить, и `todo`-пометку нужно снять.
- GitHub Actions `ci.yml`: `npm test` на каждый push и PR.
- Правило в `CLAUDE.md`: тесты после каждой правки, одна правка — одна короткая ветка.
