# Самый большой шар (размер 6) вылетает за верх экрана

- **Важность:** low
- **Тип:** bug (физика)
- **Статус:** open
- **Где:** [index.html](../../index.html) — `sizes[6]`, `Circle.gravity()`
- **Найдено:** автотестами (`tests/02-physics.test.js`, todo)

## Описание
Для размера 6 (`r=80`, `bs=9`, `weightMod=0.4`) верхняя точка шара уходит примерно на 34 px выше экрана. В текущих уровнях такой шар не используется, но он понадобится для новых уровней. Для размеров 0–5 проверка проходит.

## Решение
Подобрать `bs`/`weightMod` или ограничить апекс; решать вместе с физикой подбрасывания ([decisions.md](../decisions.md), п. 1).
