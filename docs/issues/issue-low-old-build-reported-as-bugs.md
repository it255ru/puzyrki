# Сообщено: «второй игрок после победы» и «управление на A/D» — на самом деле старая сборка

- **Важность:** low
- **Тип:** bug report / диагностика
- **Статус:** done (PR fix/build-version-label) — актуальный код дефектов не содержит; добавлена метка версии
- **Сообщил:** владелец проекта (2026-10-21)

## Сообщение
1. После победы снова появляется второй игрок в одиночной игре.
2. Управление не на стрелках, а на A/D.

## Проверка
Оба симптома относятся к сборке до PR «New controls» (клавиши A/D и Enter как выстрел второго игрока; горячее подключение). Проверено в реальном Chrome (headless, CDP), сценарий: меню → одиночная игра → нажатие A/D и →/← → победа → Enter → GAME OVER → Enter.

| Версия | Меню выбора управления | A/D двигают | Стрелки двигают | Игроков после победы + Enter | Игроков после GAME OVER + Enter |
|--------|------------------------|-------------|-----------------|------------------------------|----------------------------------|
| `index.html` на `main` (локально) | есть | нет (0 px) | да (≈90 px) | 1 | 1 |
| Опубликованная на GitHub Pages | есть | нет (0 px) | да (≈95 px) | 1 | 1 |

То есть в актуальной версии воспроизвести баги не удалось; они воспроизводятся только в старых копиях игры (A/D + Enter) — вероятнее всего, открыта старая копия файла или страница из кеша браузера.

## Что сделано
- В игру добавлена **метка версии** (`версия: <хеш коммита> <дата UTC>`) на титульном экране и на экране паузы, в правом нижнем углу. Локально — `версия: dev`. При публикации workflow Pages подставляет в `index.html` короткий хеш и время сборки (`const BUILD = "__BUILD__"`), с проверкой, что подстановка выполнена.
- По метке сразу видно, актуальна ли открытая версия. Если метки нет, значит открыта старая копия или страница из кеша.
- Тесты: наличие единственной заглушки, подстановка через workflow, отображение на титуле и паузе, положение в углу.

## Если баги всё же видны
Проверить: на титульном экране есть заголовок «Как управлять?» и в правом нижнем углу «версия: …». Если нет — обновить страницу без кеша (Ctrl+Shift+R) или открыть https://it255ru.github.io/puzyrki/; если метка есть, а баг воспроизводится — прислать значение метки и шаги.
