# Браузерный smoke-тест (Playwright) в CI

- **Важность:** medium
- **Тип:** infrastructure
- **Статус:** open
- **Решение:** [decisions.md п. 12](../decisions.md) — вариант A

## Требование
- Dev-зависимость `@playwright/test` (единственная); конфиг запускает `index.html` по `file://` или через `npx serve` для Pages-проверки.
- Сценарии: страница загружается без ошибок в консоли; канвас 1280×720 логических; нажатие клавиш двигает игрока; выстрел; снимок канваса не пуст (есть цветные пиксели шара и игрока); пауза и GAME OVER показывают оверлей; resize не создаёт прокрутку ([issue](issue-medium-canvas-border-overflow.md)).
- Отдельный job в `ci.yml` (Chromium), кэширование браузера, артефакты со снимками при падении.
- Команда `npm run test:e2e`; `npm test` остаётся быстрым Node-набором без браузера.
