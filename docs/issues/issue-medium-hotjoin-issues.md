# Горячее подключение игроков: наложение, работа на паузе и на экране конца игры

- **Важность:** medium
- **Тип:** bug
- **Статус:** open
- **Где:** [index.html](../../index.html) — `hotJoin()`, `step()`

## Описание
- Новый игрок создаётся в `x = c.w / 2` без вызова `positionPlayers()`: он накладывается на уже стоящих в центре игроков.
- `hotJoin()` вызывается каждый кадр независимо от `gameState` и `pause` — игроков можно добавлять/удалять на паузе и на GAME OVER.
- Новый игрок не получает неуязвимости; если шар рядом — жизнь теряется сразу.
- Удалённый игрок оставляет свои гарпуны на поле.

## Решение
Вызывать `positionPlayers()` после изменения состава, разрешить `hotJoin` только в `playing` и без паузы, подчистить гарпуны удалённого игрока.
