# Первый уровень проходится дважды

- **Важность:** high
- **Тип:** bug (логика)
- **Статус:** done (PR fix/first-level-played-twice)
- **Где:** [index.html](../../index.html) — `logic()`, `levelCountdown`, `restart()`
- **Найдено:** автотестами (`tests/05-game-flow.test.js`, todo)

## Описание
`levelCountdown` изначально `0`, а `restart()` тоже ставит `0` и вызывает `loadLevel(0)`. В `logic()` ветка «шаров нет» трактует `0` как «пора загрузить уровень» — поэтому после очистки уровня 1 `logic()` в первый раз не переходит к уровню 2, а заново загружает уровень 1 (`levelCountdown = -1; loadLevel(level)`). Игрок проходит первый уровень два раза после каждого старта и рестарта.

## Воспроизведение
Новая игра → убрать все шары → через несколько кадров `level` по-прежнему `0`, шары загружены заново.

## Решение
Инициализировать `levelCountdown = -1` (состояние «уровень загружен») в начале игры и в `restart()`, либо завести явное состояние `"loading"`. Тесты `сразу после старта…` и `после restart()…` переведутся из todo в обычные.
