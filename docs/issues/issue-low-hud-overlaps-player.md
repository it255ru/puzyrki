# HUD рисуется поверх игрока и смешивает языки

- **Важность:** low
- **Тип:** UX
- **Статус:** open
- **Где:** [index.html](../../index.html) — `drawHUD()`, `drawOverlay()` вызовы

## Описание
- Текст HUD на `y = c.h - 15` перекрывает прямоугольник игрока (его нижняя половина — `c.h-25 … c.h`) и рисуется поверх него.
- Заголовки оверлеев английские (`GAME OVER`, `PAUSE`), остальное — русское («Уровень», «ПОБЕДА!»).
- Во время паузы между уровнями (`levelCountdown`) HUD уже показывает следующий номер уровня, а на экране ещё пусто.

## Решение
Вынести HUD вверх экрана; единый язык (или словарь строк); показывать «Уровень N» во время отсчёта.
