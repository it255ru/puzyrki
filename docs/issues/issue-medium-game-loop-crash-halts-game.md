# Исключение в `logic()`/`paint()` навсегда останавливает игру

- **Важность:** medium
- **Тип:** robustness
- **Статус:** open
- **Где:** [index.html](../../index.html) — `step()`

## Описание
`requestAnimationFrame(step)` вызывается последней строкой `step()`. Любое исключение раньше (например, `sizes[size]` с неверным размером в `new Circle`) прерывает цикл: канвас замирает, пользователь ничего не видит, кроме ошибки в консоли.

## Решение
Планировать следующий кадр в начале `step()` или обернуть тело в `try/catch` с выводом сообщения на канвас. Дополнительно валидировать `size` в конструкторе `Circle`.
