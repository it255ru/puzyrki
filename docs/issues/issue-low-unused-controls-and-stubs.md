# Мёртвый код и незадействованные заглушки

- **Важность:** low
- **Тип:** lint / cleanup
- **Статус:** open
- **Где:** [index.html](../../index.html)

## Список
- Действия `up`/`down` в `controls` не используются (`Player.update` читает только left/right/shoot).
- `Enemy.intersects` — пустая заглушка; реализация только в `Circle`.
- `weightMod: 1` в `sizes` дублирует дефолт `|| 1`.
- `Harpoon.modifiers` — мутируется входной объект `modifiers`.
- Комментарии «НОВОЕ / ИСПРАВЛЕНО» — следы правок, не поясняют код.
- `return false` в обработчиках событий бессмысленен (используется `preventDefault`).

## Решение
Удалить или реализовать; убрать устаревшие комментарии.
