# Звук

- **Важность:** low
- **Тип:** feature
- **Статус:** open
- **Решение:** [decisions.md п. 10](../decisions.md)

## Требование
- `AudioContext` создаётся по первому нажатию клавиши (экран «Нажмите любую клавишу», автозапуск запрещён браузерами).
- Эффекты: выстрел, попадание/деление, лопание о шипы, потеря жизни, победа, GAME OVER. Файлы WAV/OGG в `assets/sounds/`, источники — CC0 (kenney.nl, opengameart.org) или свои; список с источниками и лицензиями в `assets/CREDITS.md`.
- Музыка — по желанию.
- Клавиша M выключает/включает звук; состояние хранится в `localStorage` (try/catch).
- Игра остаётся одним файлом; отсутствие звуковых файлов не должно ломать игру (ошибка загрузки → тишина).

## Тесты
Звук не создаётся до первого нажатия; переключение M; неудачная загрузка не бросает исключений (заглушка `Audio`/`fetch`).
