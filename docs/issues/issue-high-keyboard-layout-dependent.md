# Управление не работает на нерусской/нелатинской раскладке

- **Важность:** high
- **Тип:** bug (ввод)
- **Статус:** open
- **Где:** [game.html](../../game.html) — `controls`, `paused()`, `step()`, обработчики `keydown`/`keyup`

## Описание
Карта `controls` и служебные клавиши (`p`, `r`, `f2`, `*`, `/`) сопоставляются по `e.key`. На русской раскладке `e.key` для физической «A» — `ф`, для «P» — `з`, и т. д. Игрок 1 (WASD), игроки 2–4, пауза по P и рестарт по R перестают работать, пока не переключить раскладку. `e.code` (`keya`, `keyp`) сохраняется в `currentKeys`, но нигде не используется.

## Решение
Сопоставлять физические клавиши по `e.code` (`KeyA`, `Space`, `ShiftLeft`, `Numpad4`, `Minus` …), а `e.key` оставить только как запасной вариант. Обновить `controls` и `docs/gameplay.md`.
