# Пузырьки — документация

Рабочее название раньше — Bubble-Trubble. Аркада в духе Bubble Bobble / Pang: игрок стреляет гарпуном вверх, шары разбиваются на меньшие, пока не исчезнут. Касание шара стоит жизни.

Вся игра — один файл [../index.html](../index.html): HTML + Canvas 2D + чистый JavaScript, без зависимостей и сборки. Запуск: открыть файл в браузере.

## Коротко

- Холст 1280×720 логических пикселей, масштабируется под окно (до 1.25×).
- До 2 игроков на одном устройстве: клавиатура (стрелки, ↑ — выстрел) и/или мышь (смещение — движение, левая кнопка — выстрел); способ выбирается в меню старта.
- Кампания из 12 уровней (три обучающих), по 3 жизни у каждого игрока, состояния `playing` / `gameover` / `win`.
- Очки с комбо и рекорд в `localStorage`. Нет звука, бонусов, платформ.
