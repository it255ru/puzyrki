# Bubble-Trubble — документация

Аркада в духе Bubble Bobble / Pang: игрок стреляет гарпуном вверх, шары разбиваются на меньшие, пока не исчезнут. Касание шара стоит жизни.

Вся игра — один файл [../game.html](../game.html): HTML + Canvas 2D + чистый JavaScript, без зависимостей и сборки. Запуск: открыть файл в браузере.

## Коротко

- Холст 1280×720 логических пикселей, масштабируется под окно (до 1.25×).
- До 4 игроков на одной клавиатуре (горячее подключение).
- 5 уровней, 3 общие жизни, состояния `playing` / `gameover` / `win`.
- Нет очков, звука, бонусов, платформ, сохранений.
