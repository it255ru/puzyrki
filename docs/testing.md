# Тестирование

Два набора тестов; оба идут в CI на каждый push и PR.

| Набор | Команда | Что проверяет | Время |
|-------|---------|---------------|-------|
| **Модульные** (`tests/`) | `npm test` | логика игры в Node с заглушками DOM и Canvas: физика, попадания, жизни, очки, меню, уровни, ввод; «идеальный стрелок» проходит все уровни | ≈ 3 с |
| **Браузерные** (`e2e/`) | `npm run test:e2e` | настоящий Chromium: загрузка страницы, отрисовка, клавиатура, мышь с Pointer Lock, `localStorage`, масштабирование окна, все 12 уровней | ≈ 20 с |

Оба набора вместе: `npm run test:all`.

## Модульные тесты (`tests/`)
- Встроенный `node:test`, без зависимостей. Харнесс `tests/harness.js` запускает скрипт из `index.html` в Node; внутренности игры доступны как `t.g.*` (состояние, функции, константы).
- `tests/oracle.js` — «идеальный стрелок» для проверки проходимости уровней, см. [balance.md](balance.md).
- Известные баги помечаются `todo` со ссылкой на issue; после исправления пометку снимают.

## Браузерные тесты (`e2e/`)
- Playwright (`@playwright/test`, единственная dev-зависимость). Конфиг — `playwright.config.js`.
- `e2e/serve.js` поднимает статический сервер на `index.html` и `assets/` — ровно то, что публикует GitHub Pages — и **подставляет метку сборки** так же, как workflow Pages (тест проверяет и подстановку).
- `e2e/helpers.js`: страница сама следит за ошибками — **любое `console.error` или исключение на странице валит тест** (поэтому, например, у страницы есть встроенный значок: иначе браузер запрашивает `favicon.ico` и получает 404).
- Состояние игры читается прямо из страницы (`page.evaluate(() => gameState)`): скрипт глобальный.
- Нажатия, которые игра читает по шагам (выстрел, пауза, рестарт), делаются с удержанием ≈ 90 мс (`hold`) — быстрее одного шага (16,7 мс) их можно не заметить.

| Файл | Сценарии |
|------|----------|
| `smoke.spec.js` | загрузка без ошибок, титульный экран и золотой заголовок, метка версии, нет прокрутки, 60 шагов/с, все 12 уровней рисуются, шипы только где нужны, пять размеров окна |
| `keyboard.spec.js` | меню с клавиатуры, стрелки (A/D не действуют), ↑ стреляет (пробел/Enter нет), прилипший гарпун, пауза, потеря фокуса, потеря жизни, GAME OVER и победа без второго игрока |
| `mouse.spec.js` | захват курсора, смещение двигает, левая кнопка стреляет (правая нет), потеря захвата → пауза → клик, игра вдвоём (стрелки + мышь), меню мышью, клик перезапускает |
| `scoring.spec.js` | очки и комбо, рекорд в `localStorage` и после перезагрузки, повреждённый рекорд, бонус за шипы, промах обнуляет серию |

### Запуск локально
```
npm ci                              # один раз
npx playwright install chromium     # один раз (≈ 150 МБ)
npm run test:e2e
```
Тесты идут в полноценном Chromium (новый headless-режим). Без загрузки браузера можно использовать установленный Chrome: `PW_CHANNEL=chrome npm run test:e2e`. Прогонялись и в бандл-Chromium 156, и в Chrome 155 — результаты одинаковые.

Разбор падения: `npx playwright show-trace test-results/<тест>/trace.zip`; в CI отчёт и трассировки сохраняются артефактом `playwright-report` (7 дней).

## Правило проекта
После каждой правки — `npm test`. Если правка затрагивает ввод, меню, отрисовку, игровой цикл, мышь или масштабирование — ещё и `npm run test:e2e`. Красные тесты не коммитятся.
